    DevOps & Sysadmin tools

    Servers, containers, uptime, config. kodilo has 48 free DevOps & Sysadmin tools, including Uptime / SLA Calculator, Byte Size Converter, Transfer Time Calculator and Kubernetes Resource Units, and more. Every tool runs entirely in your browser, with no sign-up and no data sent to a server.

    • Uptime / SLA CalculatorTurn 99.9% into allowed downtime per day, month and year, and back.
    • Byte Size ConverterB, KB, KiB, MB, MiB, GB, GiB, TB, TiB: decimal and binary units side by side.
    • Transfer Time CalculatorHow long a file takes to move over a given bandwidth, and the bandwidth a deadline needs.
    • Kubernetes Resource UnitsCPU millicores and memory quantities (Mi, Gi, M, G) converted and explained.
    • Kubernetes Manifest GeneratorDeployment, Service and Ingress YAML from a short form.
    • .env ToolValidate, diff and convert .env files to JSON, docker -e flags or a Kubernetes Secret.
    • YAML Validator & FormatterValidate YAML with line-precise errors, format it, convert it to JSON.
    • Nginx Config GeneratorReverse proxy, static site, SPA fallback, HTTPS redirect and gzip in a few clicks.
    • systemd Unit GeneratorService and timer units with restart policy, user, environment and hardening options.
    • SSH Config GeneratorHost blocks for ~/.ssh/config with jump hosts, identity files and port forwarding.
    • htpasswd Generatorbcrypt or SHA entries for Nginx and Apache basic auth.
    • DNS Record BuilderSPF, DMARC, CAA and MX records built and explained, ready to paste.
    • Security Headers BuilderContent-Security-Policy, HSTS, Permissions-Policy and friends, for Nginx, Apache or a meta tag.
    • X.509 Certificate DecoderPaste a PEM certificate: subject, issuer, SANs, validity, fingerprints.
    • SemVer CalculatorCompare versions and test ranges like ^1.2.0, ~2.3 or >=1 <2.
    • .gitignore GeneratorCombine templates for languages, frameworks, editors and operating systems.
    • JSON Log ViewerPaste structured logs, filter by level and field, read them as a table.
    • curl ConverterTurn a curl command into fetch, axios, Python requests or HTTPie.
    • Well-Known PortsSearchable reference of common TCP and UDP ports and the services behind them.
    • Linux Signals & Exit CodesWhat SIGTERM, SIGKILL or exit code 137 actually mean.
    • Redirect GeneratorWrite redirects once and get Nginx, Apache, Netlify, Vercel and Caddy rules.
    • GitHub Actions Workflow GeneratorGenerate a CI workflow for Node, Python, Go, Docker or GitHub Pages with a version matrix, caching, least-privilege permissions and concurrency control.
    • Dockerfile Generator & LinterGenerate a multi-stage Dockerfile with a non-root user, health check and .dockerignore, or lint an existing Dockerfile line by line.
    • Docker Compose ValidatorValidate a compose file for YAML errors and semantic mistakes like bad ports, unknown services, undefined networks and volumes.
    • Kubernetes Secret EncoderTurn key/value pairs or a .env file into a Secret manifest with UTF-8 safe base64, or decode an existing Secret.
    • Caddyfile GeneratorBuild a Caddyfile with a reverse proxy or static site, www redirect, basic auth, security headers, compression and logging.
    • Firewall Rule GeneratorDescribe your firewall rules once and get them as ufw commands, an iptables-save file or a complete nftables ruleset.
    • Logrotate Config GeneratorBuild an /etc/logrotate.d file with schedule, compression, permissions and a reload script, then dry-run it with logrotate -d.
    • fstab Entry GeneratorBuild a correct /etc/fstab line for disks, network shares, tmpfs and swap, with every field explained and common mistakes flagged.
    • rsync Command BuilderBuild a safe rsync command for local or SSH copies, with excludes, bandwidth limits and a live explanation of the trailing slash rule.
    • find Command BuilderCompose a find command from name, type, size, age, owner and permission filters, prune folders and pick an action.
    • tar Command BuilderCreate, extract or list tar archives with gzip, bzip2, xz or zstd, and get the matching opposite command.
    • GitLab CI GeneratorGenerate a modern .gitlab-ci.yml with stages, cache keyed on the lockfile, artifacts, rules, needs and a manual deploy job.
    • Docker Command ExplainerPaste a docker command to see every flag explained in plain English, risky options flagged, and a host-to-container diagram of ports, mounts, network and env.
    • Docker Compose VisualizerPaste a compose file to see its services, dependencies, networks, volumes and published ports as a diagram, with a plain-English summary of each service.
    • Dockerfile Layer VisualizerPaste a Dockerfile to see its stages and layers, how stages copy from each other, and which layers a file change rebuilds.
    • Docker Container LifecycleExplore the states a container goes through, the command behind every transition, the signals sent and what exit codes mean, then drive a demo container yourself.
    • Cron Expression TesterDescribe a cron expression in plain English and list its next 10 run times in your timezone.
    • Terraform Plan VisualizerSee what a terraform plan will create, update, replace and destroy, grouped by resource with risky changes flagged
    • Helm Values ConverterConvert a values.yaml into helm --set flags and back, with dots, commas, lists and strings escaped
    • Nginx Location TesterFind which nginx location block matches a request URI and why, following the real matching order
    • SSH Key FingerprintGet the type, size, SHA256 and MD5 fingerprints and comment of an OpenSSH public key
    • IAM Policy VisualizerRead an AWS IAM or S3 bucket policy as allow and deny cards, with wildcard and public access risks flagged
    • PromQL ExplainerBreak a PromQL query down step by step: selectors, ranges, functions, aggregations and vector matching
    • iptables ExplainerRead iptables -L -n -v or iptables-save rules in plain English, chain by chain, with packet flow
    • ps and top ExplainerExplain ps aux and top output: columns, process states and a sortable table of the heaviest processes
    • Access Log AnalyzerAnalyze nginx and Apache access logs: status codes, top IPs and URLs, traffic chart, errors and bots.
    • Cron to systemd TimerTurn a cron expression into systemd .timer and .service units, preview next runs, and convert OnCalendar back to cron.
